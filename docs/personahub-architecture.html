PersonaHub 核心概念架构图

解释 Project、Workspace、Issue、Thread、Room、Agent、Workflow、Evidence、Memory/Skill 的关系
PRD 思维导图

图例

逻辑管理层：Project / Issue，用来组织工作。
协作会话层：Thread / Room，用来承载对话和阶段协作。
Agent 编排层：Coordinator 与其他 agents 都是 Agent role。
执行与环境层：Workspace / Local Runner / Runtime。
结果与沉淀层：Artifacts / Evidence / Memory / Skill。
安全边界：Escalation / Provenance / Workspace Lock。

Project vs Workspace

Project 是 PersonaHub 的逻辑管理空间；Workspace 是 agent 真正读写文件、运行命令的位置。

Issue vs Thread

Issue 管目标和状态；Thread 记录围绕 Issue 发生的消息、事件、交接、验证和证据。

Room

Room 是阶段性的结构化协作室，归属 Issue，并绑定自己的 room thread。

Coordinator Agent

Coordinator 是一种 Agent role，不是主从结构。它负责理解目标、推荐 workflow/topology、拉群和汇总。

长期记忆、Skill、Scheduled Issue 写入前必须有来源、信任等级和确认状态。

Safety

Escalation

权限、不可逆操作、跨 Workspace 写入、多轮不收敛时阻塞等待 Human Lead。

推荐理解方式：Issue owns Rooms；Room 绑定自己的 Thread；Primary Thread 是 Issue 级总控线程。Project 管逻辑，Workspace 管真实文件与执行环境。
