## 4. 需求

- 普遍性需求：`系统应当 ...`
- 事件触发：`当 <触发条件> 时，系统应当 ...`
- 状态约束：`在 <状态> 期间，系统应当 ...`
- 异常行为：`如果 <错误/非法条件>，系统应当 ...`
