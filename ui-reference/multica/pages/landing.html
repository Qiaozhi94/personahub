Write Migration

Generate a SQL migration file based on the requested schema changes. Validates against the current database state and generates both up and down migrations.

Steps

  1. Analyze the current schema from migrations/
  2. Generate migration SQL with proper ordering
  3. Validate with sqlc compile
  4. Run tests against a fresh database

开始使用

招募你的第一个 AI 员工
只需一小时。

01

注册并创建您的工作空间

输入您的邮箱，验证代码后即可使用。工作空间会自动创建——无需设置向导或配置表单。

02

安装 CLI 并连接你的机器

运行 multica setup——它会引导你完成 OAuth 登录、启动守护进程、并扫描 14 款支持的 AI 编程工具（Antigravity、Claude Code、CodeBuddy、Codex、Cursor、Copilot、Hermes、Kimi、Kiro CLI、OpenCode、OpenClaw、Pi、Qoder、Trae CLI）。本机已安装的工具会被自动注册成运行时。

03

创建你的第一个 智能体

给它起个名字，写好指令，附加技能，设置触发器。选择它何时激活：被指派时、有评论时、被 @提及时。

04

指派一个 Issue 并观察它工作

从指派人下拉菜单中选择你的 智能体——就像指派给同事一样。任务自动入队、领取、执行。实时观看进度。

两者都有。你可以用 Docker Compose 或 Kubernetes 在自己的基础设施上自托管 Multica，也可以使用我们的托管云版本。你的数据，你选择。

编码 智能体 擅长执行。Multica 添加的是管理层：任务队列、团队协作、技能复用、运行时监控，以及每个 智能体 在做什么的统一视图。把它想象成你的 智能体 的项目经理。

可以。Multica 管理完整的任务生命周期——入队、领取、执行、完成或失败。智能体 主动报告阻塞并实时推送进度。你可以随时查看，也可以让它们运行整晚。

取决于你的硬件。每个 智能体 有可配置的并发限制，你可以连接多台机器作为运行时。开源版本没有任何人为限制。
