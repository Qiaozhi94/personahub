# 产品定位

PersonaHub 是一个个人优先、开源可自托管的 AI Agent Team OS。它把真实项目内容、Agent 协作、阶段成果和验证证据放进同一个持续工作的项目空间。

以 Issue 管理目标，以可执行 Work Graph 组织 Agent 协作，以 Evidence 验证结果。

# 核心概念

Project

长期工作空间。组织 Issues、Rooms、Artifacts、Evidence、Memory 与 Skills。

Issue

目标和生命周期容器。Issue 负责“要完成什么”，Thread 记录“如何一路发生”。

Room

某个复杂阶段的协作与控制边界。Human Lead 可以旁听、暂停、纠偏、改派和恢复， 但 Room 不拥有第二套执行状态机。

# 可信完成

  • Agent 自称完成不等于 Done。
  • 验证必须针对明确版本，并留下可追溯 Evidence。
  • 阶段成果以固定 revision 的 Artifact 交接。
  • 高风险 Memory 与 Skill 在进入长期状态前需要确认来源。
