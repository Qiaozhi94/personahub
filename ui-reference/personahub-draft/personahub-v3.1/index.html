某个复杂阶段的协作与控制边界。Human Lead 可以旁听、暂停、纠偏、改派和恢复， 但 Room 不拥有第二套执行状态机。

ADR 0012 · 对象模型简化

状态：提案中 · 2026-08-29

背景

V3 迭代到一半时，对象清单已经涨到 11 个。清单越长，「这件事该记在哪」就越难回答；而回答不了这个问题，用户就会把所有东西都堆进会话。

决策

  1. 取消 AI 成员。执行单元就是 adapter + 模型 + 深度，例如 codex-gpt5.6-high。给执行单元起名字会诱导「它是个 reviewer」这类误解。
  2. 取消 Project Thread 与 primary Thread。
  3. 取消 Room 归档与父子 Issue，后者用 labels 代替。
  4. 上下文范围在每次派工时决定，不由 Room 推导——换个人做不该需要重开一个 Room。

后果

Squad 保留，但能力边界必须写成结构化字段（受 ADR 0007 约束），否则「独立验证」只是一句写在描述里的口号。
